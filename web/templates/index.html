    Настройки

    Выберите раздел, измените параметры и сохраните настройки один раз.

    Подключение и чтение карты

    Адрес сайта, селекторы и формат координат для таблицы и хронологии.

    Обход карты и поиск номеров

    Обзорный масштаб подгружает маркеры, затем программа приближается к группам и ждёт появления номеров.

    Секторы обхода

    В режиме секторов укажите центр lat/lng и радиус. Объекты вне секторов не участвуют в поиске номеров.

    Снимки и архив HTML

    Сохранение выполняется во время обхода, когда на карте появились номера объектов.

    Стационарные объекты и зоны

    Пороги расстояний определяют цвет объектов в таблице и зоны оповещений.

    Статичные объекты (вручную)

    Канонические координаты — lat/lng. При зуме и сдвиге карты x/y пересчитываются, расстояние в километрах не меняется. Если задать только x/y, lat/lng снимутся с текущего вида карты.

    Оповещения в MAX

    Настройте получателей, стационарные объекты и зоны, при входе в которые отправлять сообщение.

    Получатели и правила

    Ограничивает перечень расстояний в сообщении MAX; зоны оповещений не меняет.

    Введите несколько MAX user ID через пробел или запятую. Выберите «Все объекты» либо добавьте нужные точки по одной; в каждой группе точка может быть выбрана только один раз.
